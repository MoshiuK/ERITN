# Crypto Trading Advisor

A self-contained crypto trading advisor with daily compounding tracker, signal management, and portfolio analytics.

## Features

- **Daily Compounding Calculator** - Target 1.25% daily compound growth
- **Signal Tracker** - Log and track trading signals with entry/exit prices
- **Portfolio Dashboard** - Track holdings, P&L, and compound growth
- **Market Data** - Live prices from CoinGecko public API (no key required)
- **Trading Guidance** - RSI, moving average, and volume-based trade suggestions

## Quick Start

```bash
cd crypto-trading-advisor
python3 server.py
```

Then open http://localhost:8080 in your browser.
